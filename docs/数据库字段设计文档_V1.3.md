## 第一章 概述

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **后端生成主键** | 所有 `id` 字段在后端用 `uuid.Must(uuid.NewV7()).String()` 生成，不依赖数据库默认值，便于业务层提前获取 ID |
| **GORM 优先** | 字段类型与 GORM 标签对齐，避免使用 GORM 不友好的数据库特性（如原生 ENUM） |
| **索引覆盖查询** | 所有查询场景均有对应索引，后台筛选、排序不扫全表 |
| **审计可追溯** | `order_timeline` 记录工单全生命周期操作，`audit_logs` 记录管理员关键操作 |

### 1.2 数据库选型

| 项目 | 说明 |
|------|------|
| 数据库 | PostgreSQL 15+ |
| 字符集 | UTF-8 |
| 时区 | TIMESTAMPTZ（UTC 存储，应用层转 Asia/Shanghai） |
| 主键策略 | UUID v7（后端生成，`github.com/google/uuid`） |
| ORM 框架 | GORM v2（`gorm.io/gorm` + `gorm.io/driver/postgres`） |
| 软删除 | **不使用** `gorm.DeletedAt`，所有删除记录到 `audit_logs`，数据永久保留 |

### 1.3 命名规范

| 对象类型 | 规范 | 示例 |
|----------|------|------|
| 表名 | 小写 + 下划线，复数 | `repair_orders` |
| 字段名 | 小写 + 下划线 | `enterprise_id` |
| 主键 | `id`（UUID） | `id UUID PRIMARY KEY` |
| 状态字段 | `status`（VARCHAR + Go 常量） | `status VARCHAR(20) NOT NULL DEFAULT 'draft'` |
| 索引 | `idx_表名_字段` | `idx_orders_status` |
| 时间戳 | `created_at`, `updated_at` | TIMESTAMPTZ，GORM 自动管理 |

## 第二章 核心表字段详解

### 2.1 enterprises — 企业表

| 序号 | 字段名 | 类型 | 约束 | 默认值 | 说明 |
|------|--------|------|------|--------|------|
| 1 | id | UUID | PRIMARY KEY | — | 企业唯一标识，后端生成 UUID v7 |
| 2 | name | VARCHAR(50) | NOT NULL | — | 企业名称 |
| 3 | invite_code | VARCHAR(8) | NOT NULL, UNIQUE | — | 邀请码，6位字母数字组合，系统自动生成 |
| 4 | auto_approve | BOOLEAN | NOT NULL | FALSE | 是否免审核加入 |
| 5 | status | SMALLINT | NOT NULL | 1 | 1=正常 / 0=已注销 |
| 6 | created_at | TIMESTAMPTZ | NOT NULL | NOW() | 创建时间（GORM autoCreateTime） |
| 7 | updated_at | TIMESTAMPTZ | NOT NULL | NOW() | 更新时间（GORM autoUpdateTime） |

**GORM 模型：**

```go
type Enterprise struct {
	ID                  string       `gorm:"primaryKey;type:uuid"`
	Name                string       `gorm:"type:varchar(50);not null;uniqueIndex"`
	InviteCode          string       `gorm:"type:varchar(8);not null;uniqueIndex"`
	AutoApprove         bool         `gorm:"not null;default:false"`
	Status              int          `gorm:"not null;default:1;index"`
	CreatedAt           time.Time    `gorm:"autoCreateTime"`
	UpdatedAt           time.Time    `gorm:"autoUpdateTime"`
	InviteCodeExpiresAt *time.Time   `gorm:"type:timestamptz"`
	Memberships         []Membership `gorm:"foreignKey:EnterpriseID"`
}
```

**索引：**

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| enterprises_pkey | id | PRIMARY KEY | 主键 |
| idx_enterprises_invite_code | invite_code | UNIQUE | 扫码加企业时查询 |
| idx_enterprises_status | status | BTREE | 过滤已注销企业 |

type User struct {

    AvatarUrl string     `gorm:"type:varchar(512)"`

    CreatedAt time.Time  `gorm:"autoCreateTime"`

    Role      int        `gorm:"type:smallint;not null;default:0;index"`

    Memberships    []Membership    `gorm:"foreignKey:UserID"`
    RepairOrders   []RepairOrder   `gorm:"foreignKey:ReporterID"`
    OrderTimelines []OrderTimeline `gorm:"foreignKey:OperatorID"`

}

| 序号 | 字段名 | 类型 | 约束 | 默认值 | 说明 |

| 1 | id | UUID | PRIMARY KEY | — | 关系唯一标识 |

**唯一约束：** `UNIQUE(enterprise_id, user_id)`

**GORM 模型：**

```go
type Membership struct {
    ID           string     `gorm:"primaryKey;type:uuid"`
    EnterpriseID string     `gorm:"type:uuid;not null;index:idx_memberships_enterprise"`
    UserID       string     `gorm:"type:uuid;not null;index:idx_memberships_user"`
    Role         int        `gorm:"type:smallint;not null;default:1;index"`
    Status       string     `gorm:"type:varchar(20);not null;default:'pending'"`
    JoinedAt     *time.Time `gorm:"type:timestamptz"`
    RemovedAt    *time.Time `gorm:"type:timestamptz"`
    CreatedAt    time.Time  `gorm:"autoCreateTime"`

    Enterprise Enterprise `gorm:"foreignKey:EnterpriseID"`
    User       User       `gorm:"foreignKey:UserID"`
}
```

| 15 | updated_at | TIMESTAMPTZ | NOT NULL | NOW() | 更新时间 |
| 16 | category | VARCHAR(20) | NOT NULL | 'other' | 报修类别（如打印机） |
| 17 | property | VARCHAR(20) | NOT NULL | 'repair' | 工单性质（repair / maintenance / inspection 等） |
| 18 | room | VARCHAR(20) | NOT NULL | — | 报修房间号/位置 |
| 19 | contact | VARCHAR(40) | NOT NULL | — | 联系方式（电话或邮箱） |
| 20 | quantity | INTEGER | NOT NULL | 1 | 数量 |
| 21 | unit_price | DECIMAL(10,2) | NOT NULL | 0 | 单价 |
| 22 | amount	| DECIMAL(10,2)	| GENERATED	| (quantity * unit_price) | 金额（自动计算） |
| 23 | metadata | JSONB | — |'{}'	| 扩展元数据 |

**状态流转图：**

```
draft ──提交──→ reported ──查阅──→ reviewed ──接单──→ processing ──完工──→ completed
  │                │                │                │
  └──────取消──────┴──────退回──────┴──────退回──────┘
  （任意非终态均可退回至 draft，退回时必填 reject_reason）
```

### 2.6 order_timeline — 工单操作时间轴

| 序号 | 字段名 | 类型 | 约束 | 默认值 | 说明 |
|------|--------|------|------|--------|------|
| 1 | id | UUID | PRIMARY KEY | — | 日志唯一标识 |
| 2 | order_id | UUID | FK → repair_orders(id) ON DELETE CASCADE, NOT NULL | — | 关联工单 |
| 3 | order_no | VARCHAR(20) | NOT NULL | — | **冗余工单号，避免联表查询** |
| 4 | operator_id | UUID | FK → users(id), NOT NULL | — | 操作人 |
| 5 | action | VARCHAR(30) | NOT NULL | — | create_draft / submit / review / accept / complete / reject / upload_receipt / cancel |
| 6 | from_status | VARCHAR(20) | — | NULL | 变更前状态 |
| 7 | to_status | VARCHAR(20) | — | NULL | 变更后状态 |
| 8 | remark | VARCHAR(500) | — | NULL | 备注（退回原因等） |
| 9 | ip_address | VARCHAR(45) | — | NULL | 操作人 IP |
| 10 | created_at | TIMESTAMPTZ | NOT NULL | NOW() | 操作时间 |

**时间轴示例：**

```
2026-07-31 09:00  张三  create_draft   null        → draft       创建报修草稿
2026-07-31 09:05  张三  submit         draft       → reported    提交上报
2026-07-31 09:30  李四  review         reported    → reviewed    管理员已查阅
2026-07-31 09:35  李四  accept         reviewed    → processing  接单维修
2026-07-31 11:00  李四  complete       processing  → completed   维修完成
```

type OrderTimeline struct {

## 附录 A — 工单号生成规则

**格式：** `WO{YYYYMMDD}{4位序号}`

**生成逻辑（后端实现）：**

```go
func GenerateOrderNo(db *gorm.DB) (string, error) {
    today := time.Now().Format("20060102")
    prefix := "WO" + today

    var lastNo string
    db.Model(&RepairOrder{}).
        Where("order_no LIKE ?", prefix+"%").
        Order("order_no DESC").
        Limit(1).
        Pluck("order_no", &lastNo)

    seq := 1
    if lastNo != "" {
        seqStr := lastNo[len(prefix):]
        if s, err := strconv.Atoi(seqStr); err == nil {
            seq = s + 1
        }
    }

    return prefix + fmt.Sprintf("%04d", seq), nil
}
```

## 附录 D — 与 V1.0 的差异对比

| 变更项 | V1.0 | V2.0 | 原因 |
|--------|------|------|------|
| 主键生成 | `DEFAULT uuid_generate_v4()` | 后端生成 UUID v7 | GORM 兼容性 + 性能（有序索引） |
| 枚举类型 | PostgreSQL 原生 ENUM | VARCHAR + Go 常量 | GORM 对 ENUM 支持有限 |
| order_timeline | 无 order_no | 增加 order_no 冗余字段 | 避免联表查询 |
| 软删除 | 企业表用软删除 | 统一物理删除 + 审计日志 | 数据永久保留，便于追溯 |
| GORM 模型 | 无 | 每个表附 GORM 模型代码 | AI 开发直接可用 |
